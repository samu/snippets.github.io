# Task Management

Task management in Snippets is built on top of the core building blocks:

- A task is simply a rich-text snippet with a title and a description.
- The completion state of a task is represented by a task attribute attached to
  the snippet.
- Task lists are dynamic collections with a filter that selects snippets based
  on their task attributes. Filter configurations can be refined further to
  include additional criteria such as due dates, start dates, priorities, and
  more.
- A task can have any attribute you choose. For example, you can add a priority
  using a string-values schema, or define an estimated size such as small,
  medium, or large. This is where the flexibility of Snippets truly shines: you
  can tailor your task management workflow exactly to your needs.
