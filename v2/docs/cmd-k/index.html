Command menu

Keep useful commands alongside your notes and find them with a shortcut.

On this page
  • How it works
  • Why this is useful

Cmd + K gives you fast access to frequently used CLI commands.

How it works

  • Store commands inside code blocks or links
  • Press Cmd + K to search
  • Press Enter to copy the command to the clipboard

Why this is useful

  • Commands live next to their documentation
  • Less context switching
  • A personal, searchable command palette

Your notes become an active working tool — not just text.
