Can I keep using Snippets for free?+

Yes. The Free plan is free forever, with unlimited notes and unlimited workspaces. It also includes folder sync and syncing across devices with GitHub.

Is Pro a subscription?+

No. Pro is a one-time $29 purchase. It adds the full icon set, plus GitHub sync with end-to-end encryption and unlimited branches.

Where will my notes be stored?+

You choose your sync target: a local folder or a GitHub repository. Read about sync and workspaces to find the setup that fits you.
