Version 0.21.0 adds more ways to configure and reuse dashboards, alongside new
tools for habits, groceries, and filtering connected notes.

## New features and improvements

- **Dashboard widths.** Set the width of a dashboard.
- **Dashboard templates.** Turn a dashboard into a reusable template.
- **Habit trackers.** Create trackers directly on dashboards.
- **Grocery lists.** Create lists for your shopping.
- **Reference filters.** Filter using `references` and `referenced-by`.
- Improved the field configurator and context-view layouts, with further styling
  and spacing adjustments throughout the app.
- Temporarily removed excessive haptic feedback on mobile.

## Bug fixes

- Restored inline search behavior.
- Corrected the layout of weekly heatmaps.

## Internal notes

- Migrated `due-date` to `schedule-date`.
- Refactored `useDimensions`.
- Made adjustments to drag-and-drop behavior.
- Repaired feedback-form submission.
- Split the app bundle to improve loading times.
